# Student Performance Prediction

Machine Learning project to predict student final grades using demographic, academic, and social attributes.

## Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Model
Random Forest Regressor

## Results
- R² Score: 0.8194312435532773
- Mean Absolute Error: 1.1381012658227847

## Key Insights
- Previous grades were the strongest predictor.
- Study time positively affected performance.
- Absences negatively impacted final grades.
